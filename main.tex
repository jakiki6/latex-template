\section{Arduino Seite}
Um unsere Verbindung zu testen, bauen wir auf der Seite des Arduinos eine einfache Verbindung auf, die die Daten zwischen dem HM-10 und der Serial-Verbindung austauschen.

Dazu verbinden wir GND mit GND, VCC mit 5V, TX mit Pin 3 und RX mit Pin 4.

Als Code flashen wir folgendes auf den Arduino UNO:

\begin{lstlisting}
#include <SoftwareSerial.h>

SoftwareSerial ss(3, 4);

void setup() {
  Serial.begin(9600);
  ss.begin(9600);
}

void loop() {
  while (ss.available()) {
    char c = ss.read();
    Serial.write(c);
  }

  while (Serial.available()) {
    char c = Serial.read();
    Serial.write(c);
    ss.write(c);
  }
}
\end{lstlisting}

Dieser Code reicht Daten zwischen dem HM-10 und der Serial-Verbindung hin und her. Dann können wir im Serial-Monitor unserer Arduino IDE sehen, was ankommt, und können auch selbst Daten senden.

if (!getPackageManager().hasSystemFeature(PackageManager.FEATURE_BLUETOOTH_LE)) {
    Toast.makeText(this, R.string.ble_unsupported, Toast.LENGTH_SHORT).show();
    finish();

\end{lstlisting}

In der onCreate Methode fügen wir dann das hinzu, um eine Instanz zu bekommen:

bluetoothManager = (BluetoothManager) getBaseContext().getSystemService(Context.BLUETOOTH_SERVICE);

Diese Methode beenden wir mit einem Aufruf zu der ensurePermissions Methode, welche so definiert ist:
\begin{lstlisting}
public boolean ensurePermissions() {
    String[] perms = Build.VERSION.SDK_INT >= 31 ? new String[]{android.Manifest.permission.BLUETOOTH_SCAN, Manifest.permission.BLUETOOTH_CONNECT, Manifest.permission.ACCESS_COARSE_LOCATION, Manifest.permission.ACCESS_FINE_LOCATION} : new String[]{Manifest.permission.ACCESS_COARSE_LOCATION, Manifest.permission.ACCESS_FINE_LOCATION};

    ActivityCompat.requestPermissions(this, perms, 0);
    for (String perm : perms) {
        if (ActivityCompat.checkSelfPermission(this, perm) != PackageManager.PERMISSION_GRANTED) return false;
    }

    return true;
}
\end{lstlisting}

Diese Methode fragt abhängig von der Android-Version nach den entsprechenden Berechtigungen und gibt zurück, ob diese erfüllt sind.
